# Specs

This directory is the source of truth for Spec-Driven Development (SDD) in
Arena SJPII.

- `active/` holds approved, current specifications.
- `decisions.md` records durable technical and product decisions.
- `changes.md` is the chronological log of completed changes.

Before changing the project, read this file and the relevant active Spec. Add
or revise a Spec before material changes, then update the decision and change
records when applicable.
